# 🌸 Beautiva

A modern and responsive beauty products website built with **HTML, CSS, and Bootstrap 5**.

This is a **group project** created to practice collaborative development with **Git and GitHub**, including branching, commits, merging, and conflict resolution.

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* Git & GitHub

## 🌐 Live Demo

[View Live Website](https://sudabasolaimankhil.github.io/Beautiva/)

## 🔀 Git Workflow

Each team member works on a separate branch, then pushes their work to GitHub for review and merging into `main`.

```text
main
├── navbar
├── hero
├── about
├── shop
└── footer
```

## 🎯 Purpose

To build a beauty products website while gaining practical experience with **Git branching and team collaboration**.

**Build • Branch • Commit • Merge 🚀**
